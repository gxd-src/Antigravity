# Antigravity: proxy-only fork

Форк confeden/Antigravity для собственного HTTP CONNECT-прокси.
Личные адреса, пароли, настройки и журналы в репозиторий не включены.

## Windows

Для сборки нужны Rust stable MSVC, C++ Build Tools и Windows SDK.

```powershell
cargo build --release --locked
.\start-antigravity.ps1
```

При первом запуске скрипт спросит адрес прокси и сохранит его в личный `proxy.local.json` (исключён из Git).
Далее достаточно запускать `start-antigravity.ps1`. Для TUI: `start-antigravity.ps1 -Tui`.
Нужен HTTP CONNECT-прокси с IP-адресом; авторизация не поддерживается.
Antigravity должен быть установлен отдельно. Перед первым запуском закройте его: скрипт применит патч с резервной копией.
Без настройки соединения отклоняются. Прямого резервного выхода нет.
TUI запускает локальную сборку и ничего не скачивает.

Отключены сторонние DNS и прокси, внешние DNS-запросы, фоновые сетевые проверки,
геолокация выхода, получение релизов автора и чтение HWID.
Обновлены TLS-зависимости с известными уязвимостями.

Подробности и ограничения: [LOCAL-BUILD.md](LOCAL-BUILD.md).
Это не межсетевой экран для Google Antigravity: его собственные обновления
и телеметрия отдельно не отключены. Старые поля интерфейса не меняют
строгую политику выхода: используется `AG_UPSTREAM_PROXY`.

Оригинальная документация: [README.upstream.md](README.upstream.md).
